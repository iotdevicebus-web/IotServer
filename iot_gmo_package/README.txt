==============================================================================
 GMO サーバー (gontaro.org) ファイルマネージャー アップロード手順
==============================================================================

【配置場所】
gontaro.org の公開フォルダ（通常は public_html または httpdocs）の直下に
「iot」という名前のフォルダを作成し、以下のファイルを配置してください。

/public_html/
└── iot/
    ├── api.php           (API 本体)
    ├── index.html        (ダッシュボード画面)
    └── .htaccess         (セキュリティ & リライト設定)

【動作確認】
1. ブラウザでアクセス:
   https://gontaro.org/iot/
   -> リアルタイムダッシュボードが表示されれば完了です！

2. ヘルスチェック確認:
   https://gontaro.org/iot/api.php?endpoint=healthz
   -> {"status":"HEALTHY",...} が返れば API 正常稼働です。
