1. システム概要 & アーキテクチャ

本ファームウェアは、Espressif 社の ESP32-S3（デュアルコア Xtensa LX7 240MHz） に向けた超低消費電力・高信頼エッジ実装です。内蔵 Wi-Fi と暗号ハードウェアアクセラレータ、外部 8MB PSRAM、および Waveshare 1.54inch 電子ペーパー (e-Paper) を統合し、クラウド本番サーバ（gontaro.org/iot/）との双方向テレメトリ通信 & 超低電力 Deep Sleep 制御 を実行します。

主な特徴とスペック (v1.1.0)

  • Waveshare 1.54" e-Paper (SSD1681 200x200) 超高視認性表示: 温度・湿度を TextSize 3（高さ 24px の特大フォント）、端末情報・通信結果を TextSize 2 で描画。描画後は 0mA 休止モード (hibernate) で Deep Sleep 中も画面を永続保持。
  • GMO クラウド本番サーバ (`gontaro.org/iot/`) 完全連動: 標準 HTTPS (443) ポート経由で api.php へ高速 JSON 送信。Web ダッシュボードからの双方向スリープ秒数変更コマンドを自動受信・RTC 記憶。
  • 8MB Octal PSRAM (SDRAM) 大容量バッファ: 外部 8MB PSRAM を活用し、最大 10,000 件（約 1.5MB、約 41 時間〜数日分） のオフラインテレメトリを完全保持。
  • 完全イベント駆動 (Zero-Polling): FreeRTOS バイナリセマフォによるハードウェア割り込み待機。ビジーウェイトやポーリング遅延を完全排除。
  • HAL 割り込みカプセル化 & 厳格マスク制御: 起床直後に即座に割り込みを禁止し、処理完了時にスリープ復帰割り込みを再有効化（チャタリング誤動作・不要ディレイの完全排除）。
  • AppConst.hpp 定数一元管理 (QC規約準拠): ピン番号・タイムアウト・通信周期・サーバ URL などのマジックナンバーを完全排除した高品質コード設計。

PC接続時の推奨ポート:
Freenove ボードには 2つの USB ポートがあります。ファームウェア書き込みおよびシリアルログの確認には、必ず 「UART」と印字された側の Type-C ポート を使用してください。

3. Waveshare 1.54" 電子ペーパー (e-Paper) 仕様 & ピン結線

本システムでは、状態表示デバイスとして Waveshare 1.54inch e-Paper Module (Rev2.1 / SSD1681 200x200) を採用しています。

e-Paper ピン ESP32-S3 GPIO 機能・役割 注意事項 / 競合回避
`BUSY` GPIO 7 ビジー状態入力 (Busy: HIGH, Ready: LOW) Octal PSRAM ピン (26〜37) 完全回避
`RST` GPIO 8 ハードウェアリセット (Active LOW) GPIO 8 割り当て
`DC` GPIO 9 コマンド/データ選択 (Data: HIGH, Cmd: LOW) GPIO 9 割り当て
`CS` GPIO 10 SPI チップセレクト (Active LOW) FSPI ネイティブ CS0
`DIN` (MOSI) GPIO 11 SPI データ送信 (MOSI) FSPI ネイティブ MOSI
`CLK` (SCK) GPIO 12 SPI クロック (SCK) FSPI ネイティブ SCK (4MHz)
`VCC` 3V3 電源 (3.3V) ESP32 3.3V 出力ピンへ接続
`GND` GND グランド 共通グランドへ接続

画面レイアウト設計 (超大型フォント最適化)

  • 初回起動 (Boot #1): 二重外枠、反転タイトル帯、幾何学テスト図形、市松模様を描画してハードウェア初期動作を完全確認。
  • 稼働中 (Boot #2〜):
    • 最上段: DEV-ESP32-001 (Boot #3)
    • 中央段 (特大フォント): TEMP: 25.4 C / HUMI: 58.2 % (TextSize 3: 高さ 24px)
    • 下段: BATT: 4.05V (95%) SLEEP: 15s (TextSize 2)
    • 最下段ステータス枠: SERVER: www.gontaro.org 200 OK (HTTPS)
  • 超低消費電力制御: 描画完了後に epd.hibernate() を実行し、コントローラをディープスリープ（消費電力 0mA）に移行。

4. 8MB Octal PSRAM & 大容量オフラインバッファ

ESP32-S3 の高速 Octal PSRAM（8MB）をフル活用し、ネットワーク不通時でもデータを失わない大容量リングバッファを構築しています。

// 8MB PSRAM 領域への大容量リングバッファ動的確保 (main.cpp)
s_psram_buffer.data = (telemetry_data_t*)heap_caps_malloc(
    AppConst::PSRAM_BUFFER_CAPACITY * sizeof(telemetry_data_t), 
    MALLOC_CAP_SPIRAM | MALLOC_CAP_8BIT
);
// 10,000 件 (約 1.5MB) を 8MB PSRAM 上で完全保持可能

6. GMO クラウド本番サーバ連携 (`gontaro.org/iot/`)

エッジマイコンは、インターネット上の GMO クラウドサーバ（https://www.gontaro.org/iot/api.php）と HTTPS ポート 443 でセキュアに通信します。

// edge/platform/esp32/AppConst.hpp の設定
namespace AppConst {
    constexpr uint16_t    SERVER_PORT           = 443;
    constexpr const char* SERVER_HOST           = "www.gontaro.org";
    constexpr const char* API_TELEMETRY_PATH   = "/iot/api.php?endpoint=telemetry";
    constexpr const char* API_COMMAND_ACK_PATH = "/iot/api.php?endpoint=commands/ack";
    constexpr const char* WIFI_SSID             = "ControlAdLab";
    constexpr const char* WIFI_PASSWORD         = "ControlAD";
}

7. クイックスタート (ビルド & 書込)

ファームウェア書き込み手順

  1. Freenove ESP32-S3 の 「UART」ポート を USB ケーブルで PC に接続します。
  2. VS Code ステータスバーの [ → ] (Upload ボタン) をクリックして書き込みを開始します。
    またはターミナルで以下を実行します： 
    C:\Users\iam\.platformio\penv\Scripts\platformio.exe run -t upload
  3. 書き込み完了後、ステータスバーの [ 🔌 ] (Serial Monitor ボタン) をクリックしてターミナル（115200 bps）を開きます。

9. トラブルシューティング (Q&A)

Q. 書き込み時に Connecting......._____ で停止します

A. ボード上の [BOOT] ボタンを押したまま [RST] ボタンを1回押し、そのあと [BOOT] を離して から、再度 Upload ボタンをクリックしてください。

Q. e-Paper の表示が更新されません

A. GPIO 配線（DIN:11, CLK:12, CS:10, DC:9, RST:8, BUSY:7）が緩んでいないかご確認ください。特に BUSY ピン（GPIO 7）の接続不良があると描画完了待機でタイムアウトします。

Q. クラウドサーバへの接続でエラーが出ます

A. ブラウザで https://www.gontaro.org/iot/api.php?endpoint=healthz を開き、{"status":"HEALTHY", ...} が返るかご確認ください。
