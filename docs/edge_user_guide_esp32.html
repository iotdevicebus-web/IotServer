1. ESP32-S3 版エッジ概要

本ファームウェアは、Espressif 社の ESP32-S3（デュアルコア Xtensa LX7 240MHz） に向けたエッジ実装です。内蔵 Wi-Fi と暗号ハードウェアアクセラレータを活用し、X.509 mTLS 相互認証・NTP 自動時刻同期・Protocol Buffers v3 通信・Deep Sleep 省電力制御 を一気通貫で実行します。

主な特徴とスペック

  • 8MB Octal PSRAM (SDRAM) 大容量バッファ: 外部 8MB PSRAM を活用し、最大 10,000 件（数日分） のオフラインテレメトリを完全保持。
  • ゼロトラスト mTLS 相互認証: デバイス固有証明書（DEV-ESP32-001 / PKCS#1 RSA）による完全な双方向暗号化通信。
  • 爆速 0ms クロックセット: 外部 NTP の遅延・遮断に依存せず、起動時に 0ms で有効期間内時刻を即時適用。
  • 超軽量 Protocol Buffers v3: データを 81 Bytes（約 72% 削減） に圧縮して高速送信。
  • Deep Sleep 制御: 通信完了後に自動スリープに入り、バッテリ寿命を数年単位に延伸。

PC接続時の推奨ポート:
Freenove ボードには 2つの USB ポートがあります。ファームウェア書き込みおよびシリアルログの確認には、必ず 「UART」と印字された側の Type-C ポート を使用してください。

3. ピンアサイン & 結線仕様

ボード上のシルク ESP32-S3 GPIO ペリフェラル機能 接続先 / 役割 回路仕様・注意事項
`3V3` 3.3V 3.3V 電源出力 センサ (SHT31) の VCC 最大 500mA 出力
`GND` GND グランド センサ・分圧回路の GND 共通グランド
`IO 8` GPIO 8 I2C SDA SHT31 / ATECC608A の SDA 4.7kΩ プルアップ抵抗推奨
`IO 9` GPIO 9 I2C SCL SHT31 / ATECC608A の SCL 4.7kΩ プルアップ抵抗推奨
`IO 1` GPIO 1 (ADC1_CH0) ADC1 バッテリ監視 LiPo バッテリ分圧回路の中間点 1/2 分圧 (100kΩ + 100kΩ)
`IO 4` GPIO 4 (RTC_IO) 外部起床スイッチ 外部プッシュスイッチ / センサ Active Low (内部プルアップ)
`IO 48` GPIO 48 オンボード RGB LED ステータス表示用 LED 稼働時点灯・スリープ時消灯
避けるべきピン（競合防止）:
  • GPIO 19, 20: 内蔵 USB ポートで使用するため、外部センサ等には接続しないでください。
  • GPIO 33 〜 37: 内部 Flash/PSRAM メモリで使用されています。
  • ADC2 系統 (GPIO 11〜20): Wi-Fi 通信中は無効化されるため、バッテリ監視には必ず ADC1 (GPIO 1) を使用してください。

4. 開発環境の準備 (VS Code + PlatformIO)

  1. VS Code を起動し、拡張機能マーケットプレイス（Ctrl + Shift + X）を開きます。
  2. 検索窓に `PlatformIO IDE` と入力してインストールします。
  3. VS Code でプロジェクトフォルダ x:\iot-platform-project を開きます。

5. Wi-Fi 設定 & ビルド手順

edge/platform/esp32/main.cpp を開き、接続先 Wi-Fi 情報および管理サーバの IP アドレスを設定します。

// edge/platform/esp32/main.cpp 内の設定箇所
static const char *MY_WIFI_SSID = "ControlAdLab";       // Wi-Fi の SSID
static const char *MY_WIFI_PASSWORD = "Your_Password";   // Wi-Fi パスワード

// IoT サーバのアドレス (PC のローカル IP アドレス)
static const char *MY_SERVER_HOST = "192.168.3.4";
static const int MY_SERVER_PORT = 8443;

VS Code 画面下部のステータスバーにある [ ✓ ] (Build ボタン) をクリックすると、数秒でコンパイルが完了（[SUCCESS]）します。

6. Flash 書込 & シリアルモニタでの確認

書き込み手順

  1. Freenove ESP32-S3 の 「UART」ポート を USB ケーブルで PC に接続します。
  2. ステータスバーの [ → ] (Upload ボタン) をクリックして書き込みを開始します。
  3. 書き込み完了後、ステータスバーの [ 🔌 ] (Serial Monitor ボタン) をクリックしてターミナルを開きます。

7. ログファイル自動保存機能

platformio.ini の monitor_filters = log2file, time 設定により、シリアルモニターを開いている間、すべての通信ログが自動的にファイルへ保存されます。

ログファイルの保存場所:

x:\iot-platform-project\edge\platform\esp32\logs\device-monitor-YYMMDD-HHMMSS.log

※ 過去の通信記録やエラー解析、バッテリ電圧推移の検証に活用できます。

8. Deep Sleep & 省電力設計

状態 消費電流 (目安) 動作内容 復帰トリガー
Active (Wi-Fi 送信中) 約 120 〜 240 mA センシング、Protobuf変換、mTLS HTTPS送信 (所要約 1.5秒) -
Deep Sleep モード 約 8 〜 10 µA Wi-Fi/CPU停止、RTCタイマーのみ稼働 RTC タイマー満了 / GPIO 4 割り込み

9. トラブルシューティング (Q&A)

Q. 書き込み時に Connecting......._____ で停止します

A. ボード上の [BOOT] ボタンを押したまま [RST] ボタンを1回押し、そのあと [BOOT] を離して から、再度 Upload ボタンをクリックしてください。

Q. (-9984) Certificate verification failed が出ます

A. NTP 時刻同期が失敗している可能性があります。Wi-Fi ルーターがインターネットに接続されており、NTP（ポート 123）が通る環境かご確認ください。

Q. POST Failed, Error: connection refused が出ます

A. 管理サーバ（PC）が起動していないか、IP アドレスが異なっています。ターミナルで cd server ➔ go run main.go を実行してサーバを立ち上げ、PC の IP アドレスと main.cpp の MY_SERVER_HOST が一致しているかご確認ください。
