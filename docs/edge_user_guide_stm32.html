1. STM32 版エッジ概要

本ファームウェアは、STMicroelectronics 社の STM32 マイコン（ARM Cortex-M シリーズ） 向けに最適化された超軽量・高信頼 IoT エッジ基盤です。HAL（Hardware Abstraction Layer）および OSAL（OS Abstraction Layer）により、マイコンのペリフェラルや RTOS 実装から完全に抽象化されています。

主な特徴とスペック

  • 極小メモリフットプリント: Flash(ROM) 約 3.6 KB / SRAM(RAM) 約 3.7 KB（※32件リングバッファ含む）。
  • ゼロ・ダイナミックメモリ: malloc() / free() を完全排除。ヒープ枯渇や断片化による長期稼働停止を根絶。
  • mTLS ゼロトラスト暗号化: デバイス固有証明書（DEV-STM32-002）による安全な通信。
  • Protocol Buffers v3 直列化: ピュア C99 でバイナリを直接生成し、パケットを約 81% 削減。

4. ビルド環境の構築 (ARM GCC & CMake)

本プロジェクトは、STM32CubeCLT またはスタンドアロンの GNU ARM Embedded Toolchain でコンパイル可能です。

推奨ツールチェーン

  • コンパイラ: arm-none-eabi-gcc 13.x+
  • ビルドシステム: CMake 3.20+ ＆ Ninja 1.10+
  • 書き込みツール: STM32CubeProgrammer または OpenOCD
# 環境変数の設定例 (Windows PowerShell)
$env:PATH = "C:\ST\STM32CubeCLT_1.19.0\GNU-tools-for-STM32\bin;C:\ST\STM32CubeCLT_1.19.0\Ninja\bin;" + $env:PATH

5. コンパイル & ビルド手順

CMake と Ninja を使用して、警告ゼロ（Warning-Free）で静的ライブラリ (`libstm32_edge_lib.a`) を生成します。

# 1. STM32 ビルドディレクトリへ移動
cd edge/platform/stm32

# 2. CMake 構成 (Cortex-M4 クロスコンパイル設定)
cmake -B build -G Ninja -DCMAKE_TOOLCHAIN_FILE=arm-toolchain.cmake

# 3. Ninja で高速ビルド
ninja -C build

# 4. バイナリサイズの確認 (arm-none-eabi-size)
arm-none-eabi-size build/libstm32_edge_lib.a
ビルド出力結果:
[3/3] Linking C static library libstm32_edge_lib.a ➔ エラー・警告ゼロで完了します。

6. Flash 書込手順 (ST-LINK)

Nucleo ボードの USB ポート（ST-LINK）を PC に接続し、STM32CubeProgrammer CLI で書き込みます。

# STM32CubeProgrammer CLI による書き込み
STM32_Programmer_CLI.exe -c port=SWD -w build/stm32_edge_firmware.bin 0x08000000 -v -rst

8. メモリ配置 & 省電力設計

STM32 動作モード 消費電流 (目安) ペリフェラル状態 復帰トリガー
Run モード (84MHz) 約 15 mA CPU全開、センシング、Protobufエンコード -
Sleep モード 約 4 mA CPU停止、DMA/I2C/UART 転送待機中 UART受信割り込み
STOP モード (推奨) 約 15 µA SRAM保持、全クロック停止、RTC動作 RTC Alarm / EXTI (PC13)
Standby モード 約 2.5 µA SRAM消去、バックアップレジスタのみ保持 WKUP ピン / RTC Alarm

9. トラブルシューティング (Q&A)

Q. ST-LINK でマイコンが認識されません

A. Nucleo ボード上のジャンパピン（CN2: ST-LINK TX/RX）が外れていないか確認してください。また、低電力スリープ（STOP/Standby）中はデバッガが切断されるため、[USER RESET] ボタンを押しながら書き込み（Connect Under Reset） を実行してください。

Q. I2C センサが HAL_ERR_TIMEOUT になります

A. I2C バス（PB8/PB9）に 4.7kΩ のプルアップ抵抗 が接続されているかテスターで確認してください。

Q. mTLS 証明書を変更したいときは？

A. tools/certs/generate_certs.ps1 -DeviceId "DEV-STM32-002" を再実行すると、device_certs.h が自動更新されます。その後 ninja -C build で再ビルドしてください。
