エッジ・クラウド間 プロトコル通信仕様書

仕様書番号: PROTO-SPEC-2026-V1.1 対象: ESP32-S3 / STM32 / GMO Cloud / Go Management Server バージョン: 1.1.0 (Final Master) 更新日: 2026-08-18

1. プロトコル概要

本仕様書は、エッジデバイス（ESP32-S3 等）とクラウド管理サーバ（GMO itpark / Go Server）間の通信プロトコル、電文フォーマット、および双方向 C2 コマンドシーケンスを定義します。

環境 接続先 URL トランスポート ペイロード形式
GMO クラウド本番 https://www.gontaro.org/iot/api.php HTTPS (Port 443) JSON
Go ローカルサーバ https://192.168.3.4:8443 mTLS (Port 8443) Protocol Buffers v3 / JSON

2. 通信フロー & シーケンス

sequenceDiagram autonumber actor Edge as ESP32-S3 (Edge) participant Cloud as GMO Cloud (gontaro.org) actor Admin as 管理者 Web UI Admin->>Cloud: POST /commands (スリープ60秒に変更) Note over Cloud: コマンドを DB に PENDING 登録 Note over Edge: ⏰ タイマー起床 (Deep Sleep 復帰) Edge->>Edge: センサ計測 & e-Paper 画面更新 Edge->>Cloud: POST /iot/api.php?endpoint=telemetry (JSON) Cloud-->>Edge: HTTP 200 (sleep_interval_sec: 60, commands: [...]) Note over Edge: スリープ時間を 60秒 に更新 (RTC保存) Edge->>Cloud: POST /iot/api.php?endpoint=commands/ack (command_id, SUCCESS) Cloud-->>Edge: HTTP 200 (ACK_RECORDED) Note over Cloud: コマンド状態を ACKED に更新 Admin->>Cloud: Web UI 自動更新 (所要時間表示) Note over Edge: 💤 Deep Sleep 移行 (60秒間 8〜10µA)

3. GMO クラウド HTTPS JSON 電文仕様

テレメトリ POST 電文 (Request)

POST /iot/api.php?endpoint=telemetry HTTP/1.1
Host: www.gontaro.org
Content-Type: application/json

{
  "header": {
    "device_id": "DEV-ESP32-001",
    "seq_no": 12,
    "timestamp": 1787035000,
    "firmware_version": "1.0.0-PROD"
  },
  "metrics": {
    "temperature": 25.40,
    "humidity": 58.20,
    "battery_voltage": 4.05,
    "battery_level_pct": 95,
    "rssi": -32,
    "interval_sec": 15
  }
}

サーバ応答電文 (Response)

HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{
  "status": "OK",
  "message": "Telemetry accepted",
  "server_time": 1787035002,
  "sleep_interval_sec": 15,
  "ota": { "available": false },
  "commands": []
}
