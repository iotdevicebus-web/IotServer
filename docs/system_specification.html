1. システム概要と設計思想

本システムは、数万台規模のエッジデバイス（MCU/RTOS）からクラウド管理サーバ、リアルタイム Web ダッシュボードに至るまでを一気通貫で統合した、高信頼・高セキュリティ・超省電力な IoT プラットフォームです。

3大コア設計原則

  • ゼロトラスト・セキュリティ: プライベート Root CA による全通信の mTLS（相互TLS）暗号化、証明書の DeviceID 偽装検知、およびハードウェア・セキュアエレメント（HSM）による秘密鍵保護。
  • HAL / OSAL 抽象化によるポータビリティ: マイコン（ESP32 / STM32）や RTOS（FreeRTOS 等）の直接依存を排除し、C言語コードを 100% 共通化。
  • 超省電力・通信効率の極大化: Protocol Buffers v3 によるパケットサイズの 約 81.2% 削減、32件オフラインリングバッファ によるデータ欠損ゼロ化、および バッテリ寿命 5.8年（1分間隔送信）。

7. IoT 管理サーバ仕様 (Go / SQLite WAL)

実装言語: Go 1.22+ (ピュア Go) | DB: SQLite (WAL モード, busy_timeout=5000ms)

-- 1. デバイスマスタ管理
CREATE TABLE IF NOT EXISTS devices (
    device_id VARCHAR(64) PRIMARY KEY,
    device_type VARCHAR(32),
    firmware_version VARCHAR(32),
    status VARCHAR(16) DEFAULT 'OFFLINE',
    last_seen_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. 時系列テレメトリデータ
CREATE TABLE IF NOT EXISTS telemetries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id VARCHAR(64),
    timestamp TIMESTAMP,
    seq_no INTEGER,
    temperature REAL,
    humidity REAL,
    battery_voltage REAL,
    battery_level_pct INTEGER,
    rssi INTEGER,
    state VARCHAR(32),
    raw_payload BLOB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

9. 異常検知ルールエンジン & Webhook

ルール名 評価条件 重要度 アクション
HIGH_TEMPERATURE Temperature > 35.0 ℃ CRITICAL 🚨 高温異常検知 ➔ Webhook 即時送信
LOW_TEMPERATURE Temperature < 0.0 ℃ WARNING ⚠️ 凍結注意 ➔ Webhook 送信
LOW_BATTERY BatteryLevelPct < 20 % CRITICAL 🚨 バッテリ低下 ➔ 交換アラート送信
WEAK_SIGNAL RSSI < -85 dBm WARNING ⚠️ 通信障害予兆 ➔ 警告送信

10. Web 監視ダッシュボード

アクセス URL: http://localhost:8080/

  • リアルタイム時系列グラフ: Chart.js による温湿度・バッテリ電圧推移。
  • デバイス一覧 & 状態表示: ONLINE/OFFLINE、最新パケット受信時刻、電波強度。
  • リモートコマンド操作パネル: デバイスを選択して CONFIG_UPDATE, REBOOT, SELF_TEST を即時配信。

11. REST API エンドポイントリファレンス

メソッド パス ポート / 認証 概要
POST /api/v1/telemetry :8443 (mTLS) テレメトリ受信 & コマンドピギーバック配信
POST /api/v1/commands/ack :8443 (mTLS) コマンド実行完了 ACK 受信
GET /api/v1/ota/download/{ver} :8443 (mTLS) 暗号化 OTA バイナリ配信
GET /api/v1/devices :8080 (HTTP) 全デバイス一覧・最新ステータス取得
GET /api/v1/telemetry/history :8080 (HTTP) 時系列テレメトリ履歴データ取得
POST /api/v1/commands :8080 (HTTP) C2 リモートコマンドの新規キュー登録
GET /healthz :8080 (HTTP) サーバ生存ヘルスチェック ({"status":"HEALTHY"})
