1. システム概要 & 設計思想

本システムは、エッジデバイス（ESP32-S3 / e-Paper）、インターネット上のクラウド本番サーバ（GMO itpark）、およびローカル mTLS 管理サーバをシームレスに統合した ゼロトラスト・超低消費電力 IoT プラットフォーム です。

主要な設計目標

  • クラウド 24時間常時運用: GMO 共用サーバ（PHP 8.4 + SQLite WAL）による 24/7 常時稼働テレメトリ収集 & リアルタイム Web ダッシュボード（https://www.gontaro.org/iot/）。
  • 電子ペーパー状態可視化: Waveshare 1.54inch e-Paper (SSD1681 200x200) を搭載し、特大フォント（TextSize 3）による温湿度表示と 0mA 休止モード（hibernate）を両立。
  • 8MB Octal PSRAM 大容量オフライン保持: ネットワーク不通時でも 10,000 件のテレメトリを保持。
  • 双方向 C2 動的スリープ制御: クラウド画面からエッジ端末の起床周期を動的制御し、RTC Fast Memory に記憶・継続。

3. セキュリティ & 暗号化仕様

  • マルチドメイン SAN 証明書: gontaro.org, *.gontaro.org, www.gontaro.org, 192.168.3.4 を 1 つの証明書で相互解決。
  • 暗号アルゴリズム: 2048-bit RSA / PKCS#1 形式。
  • 通信路暗号化: TLS 1.2 / TLS 1.3。
